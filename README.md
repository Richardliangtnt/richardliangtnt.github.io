# 梁飞的研究与技术写作主页

这是一个静态个人网站，聚焦 VRPTW、EVRPTW、元启发式算法、强化学习与可复现实验，同时展示 ROS、IoT 和 Python 工程项目。

本站采用 AI 辅助开发。研究内容、实验结果与技术观点均由梁飞负责。

## 内容结构

- `index.html`：研究主页与项目入口
- `articles/`：研究文章与写作路线
- `projects/`：论文和工程项目展示
- `assets/`：样式、脚本与图片资源

## 本地预览

```powershell
python -m http.server 8000
```

打开 `http://localhost:8000/index.html`。
